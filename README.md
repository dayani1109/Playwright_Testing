📌 Singlish to Sinhala Test Automation (Playwright)

📖 Project Description

This repository contains an automated testing solution built using Playwright (Python) to evaluate a Singlish to Sinhala translation system.

The main objective of this project is to identify failures in the translation system using negative test cases.

✔ All test cases are negative scenarios
✔ The system is tested for incorrect conversions
✔ Results are automatically recorded in an Excel file

🎯 What This Project Does

-Takes Singlish inputs from an Excel file
-Sends them to the online translator
-Captures the actual Sinhala output
-Compares it with the expected output
-Automatically marks results as:
      ✅ PASS
      ❌ FAIL
-Writes results back into the Excel file


🧪 Test Coverage

-Total Test Cases: 50
-Type: Negative Test Cases
-Covers multiple Singlish input types such as:
    Slang
    Abbreviations
    English word insertions
    Emojis
    Technical terms
    URLs, emails, numbers, dates, etc.
    
🛠️ Technologies Used
    Playwright (Python)
    openpyxl (Excel handling)
    Google Chrome / Chromium

📦 Dependencies

Install the required dependencies using:
  pip install -U pip
  pip install playwright openpyxl
  playwright install

  
▶️ How to Run the Project

Run the Playwright automation script using:

python test_automation/test_automation.py --excel "test_automation/Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --type-delay-ms 80 --slow-mo-ms 200 --save-every 1 --keep-open


📊 How It Works

-Reads test cases from the Excel file
-Sends input text to the web application
-Waits for the translated output
-Compares Expected vs Actual output
-Updates:
    Actual Output
    Status (PASS/FAIL)
